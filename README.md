# Hospital Management System — Database Design

## Overview
Designed a relational database schema for a Hospital Management System using MySQL Workbench, modeled through an EER (Enhanced Entity-Relationship) diagram.

## Key Entities
Employee, Patients, Doctor, Rooms, Bills, Records, Test Reports, Reception, Nurse

## Design Highlights
- Defined primary and foreign key relationships across all entities
- Modeled one-to-many and many-to-many relationships to maintain referential integrity
- Structured schema to support hospital operations: patient admission, billing, staff management, and diagnostics

## Tools Used
MySQL Workbench · EER Modeling · Relational
